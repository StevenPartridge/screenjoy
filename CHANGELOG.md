# Changelog

## 0.1.0 — 2026-09-16

- Nine custom-element scenes and games with a shared lifecycle runtime.
- Compact gallery chooser, direct scene links, and scene-first mobile layout.
- Movable demo window with keyboard movement, pause, reset, fullscreen, and an
  in-page expanded fallback.
- Independent package archives, consumer verification, CI, public documentation,
  and a clean source-export procedure.
